# CHƯƠNG

CHƯƠNG là nền tảng đọc, nghe và xuất bản truyện cho Android, iOS và Web.

- App độc giả: đọc truyện, nghe TTS tiếng Việt, thư viện/offline, cộng đồng, Linh Thạch và CHƯƠNG VIP.
- Author Studio: tác giả tạo truyện, đăng chương và theo dõi hiệu quả nội dung.
- Content Studio Web: Admin đẩy TXT/DOCX/ZIP, quản lý bìa, metadata, chương và trạng thái nội dung đang hiển thị trong app mobile.
- AI dịch/làm mượt toàn truyện chỉ nằm trong luồng tải truyện của tác giả và yêu cầu Premium.

Web Content Studio bắt đầu tại `/studio/login`.
